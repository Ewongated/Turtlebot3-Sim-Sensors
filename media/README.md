## Recording the voice-over

Read the script in your own words, following the timestamps. Leave a pause if
you finish a section early. Do not read the headings aloud. The script describes
the system without claiming manual authorship or independent testing that the
student has not performed. Record in a quiet room; audio can be aligned to this
cut afterwards. Only claim what you understand and have actually checked.
